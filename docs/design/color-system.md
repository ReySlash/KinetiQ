# KinetiQ Color System

## Purpose

Defines the semantic use of color throughout the application.

Color communicates meaning.

It should never be decorative.

---

# Brand Colors

Primary

Orange

Secondary

Neutral Gray

Background

Near-black navy / blue-violet

Surface

Cool dark gray with a blue-violet cast

Foreground

White

---

# Semantic Colors

Primary

Represents:

- action
- progress
- active state

Secondary

Represents:

- secondary actions

Success

Represents:

- completed
- healthy
- positive change

Warning

Represents:

- caution

Danger

Represents:

- errors
- destructive actions

Info

Represents:

- informational content

---

# Anatomy Colors

Primary Muscle

Bright Orange

Secondary Muscle

Soft Orange

Stabilizer

Muted Gray-Orange

Inactive Muscle

Dark Gray

The cool background is the foundation of the dark-first experience. Orange is
an accent reserved for actions, active states, progress, and meaningful
highlights; it should not tint the application background or large surfaces.

Bones

Neutral Gray

---

# Chart Colors

Charts should use semantic colors.

Avoid rainbow palettes.

Highlight only important data.

---

# Interaction States

Hover

Slight brightness increase.

Active

Higher contrast.

Disabled

Reduced opacity.

Focus

Visible outline.

---

# Dark Mode

Dark mode is the primary experience.

Every new color must first be evaluated against the dark theme.

---

# Light Mode

Colors must preserve semantic meaning.

Never invert meaning.

---

# Future Tokens

Eventually every color should exist as a design token.

Example:

--color-primary

--color-surface

--color-border

--color-success

etc.
