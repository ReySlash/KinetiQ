# KinetiQ Typography

## Purpose

Defines typography rules across the application.

Typography should maximize readability while maintaining a premium aesthetic.

---

# Font Philosophy

Use modern sans-serif fonts.

Typography should feel:

- clean
- technical
- premium
- timeless

Avoid decorative fonts.

---

# Hierarchy

Display

Landing pages.

H1

Page titles.

H2

Major sections.

H3

Cards.

H4

Subsections.

Body

Standard content.

Caption

Secondary information.

Overline

Labels.

---

# Numbers

Numbers are extremely important in KinetiQ.

Training data must be immediately readable.

Metrics should receive higher visual emphasis than surrounding text.

---

# Tables

Headers

Medium weight.

Values

Regular weight.

Numeric columns

Right aligned.

---

# Line Length

Avoid extremely wide paragraphs.

Aim for comfortable reading.

---

# Font Weight

Light

Rare.

Regular

Body text.

Medium

Labels.

Semibold

Headings.

Bold

Only for emphasis.

---

# Text Alignment

Left align almost everything.

Avoid centered body text.

---

# Text Color

Primary

White.

Secondary

Muted gray.

Disabled

Low contrast.

Links

Accent color.

---

# Responsive Typography

Typography should scale smoothly across:

Desktop

Tablet

Mobile

Maintain hierarchy at every breakpoint.

---

# Accessibility

Maintain readable font sizes.

Respect user zoom.

Never rely on color alone to convey meaning.

Ensure sufficient contrast ratios.

---

# Future Design Tokens

Typography should eventually be tokenized.

Example:

--font-display

--font-heading

--font-body

--font-caption

--font-mono

--font-size-h1

--font-size-body

etc.
