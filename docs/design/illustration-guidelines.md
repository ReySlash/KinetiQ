# KinetiQ Illustration Guidelines

> Version: 1.0
>
> Status: Source of Truth
>
> Owner: KinetiQ Art Direction

---

# Purpose

This document defines every rule related to visual assets used by KinetiQ.

It exists to ensure that every image generated today and years from now feels like it belongs to the same application.

Consistency is always more important than creativity.

Every asset should appear as though it was created by the same world-class creative team.

---

# Design Philosophy

KinetiQ is a premium strength training platform.

Visuals should communicate:

- scientific credibility
- precision
- professionalism
- confidence
- discipline
- performance

The application should never feel:

- cartoonish
- playful
- exaggerated
- flashy
- influencer-oriented
- bodybuilding-oriented
- unrealistic

The overall visual language should resemble premium software rather than social media.

---

Keywords

# Lighting

Global lighting should remain consistent.

Soft studio lighting.

Controlled highlights.

Subtle shadows.

No dramatic HDR.

No colored lighting except subtle orange accents.

---

# Color Grading

Neutral.

Professional.

Slightly desaturated.

Dark environments.

Orange remains the primary accent.

Avoid highly saturated colors.

---

# Background Philosophy

If a background exists,

it should provide context,

never distraction.

Backgrounds should support the subject,

not compete with it.

# File Naming Convention

Use lowercase.

Separate words with hyphens.

Examples

muscles

biceps-brachii.webp

rectus-femoris.webp

muscle-groups

quadriceps.webp

hamstrings.webp

exercises

barbell-back-squat.webp

incline-dumbbell-press.webp

equipment

olympic-barbell.webp

hex-dumbbell.webp

Never include spaces.

Never include version numbers.

# AI Generation Workflow

Whenever a new asset is requested:

3.

propose a better alternative.

4.

Generate the asset.

5.

Review:

Approve for production.
